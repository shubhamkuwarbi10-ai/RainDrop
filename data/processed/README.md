# ⚙️ Processed Datasets Directory (`data/processed/`)

This directory contains processed 30m GeoTIFF rasters, optical flow precipitation nowcast files, and JSON terrain summary profiles generated by `pipeline/process_dem.py` and `pipeline/ingest_imerg.py`.

---

## 🗺️ Processed GeoTIFF Raster Attributes & Data Types

| File Pattern | Band Count | Data Type | Units | Key Attributes & Description |
|---|---|---|---|---|
| `[city]_dem_filled.tif` | 1 | `float32` | Meters ($m$) | Continuous surface elevation $z$ with spurious sinks filled |
| `[city]_slope.tif` | 1 | `float32` | Degrees ($\theta^\circ$) | 2nd-order Sobel spatial slope angle (0.0°–90.0°) |
| `[city]_flow_direction.tif` | 1 | `float32` | Enum Pointer | D8 steepest descent codes ($1, 2, 4, 8, 16, 32, 64, 128$) |
| `[city]_flow_accumulation.tif` | 1 | `float32` | Cell Count | Upstream contributing cell count draining through each cell |
| `[city]_depressions.tif` | 1 | `float32` | Binary Mask | Topographical low-point sink mask ($1.0 = \text{sink}, 0.0 = \text{normal}$) |
| `[city]_dem_terrain.tif` | 5 | `float32` | Mixed | Multi-band GeoTIFF combining Bands 1–5 into one raster |
| `pysteps_forecast.tif` | $N$ bands | `float32` | $\text{mm/hr}$ | $N$-step optical flow extrapolated precipitation nowcast grids |

## 📋 JSON Profile Attributes (`[city]_dem_summary.json`)

Each city's `.json` file summarizes the 30m CartoDEM characteristics:

```json
{
  "city": "Chennai",
  "city_key": "chennai",
  "aoi": {
    "lon_min": 80.1, "lon_max": 80.45,
    "lat_min": 12.9, "lat_max": 13.3
  },
  "grid_resolution_m": 30.0,
  "dimensions": { "rows": 1484, "cols": 1298 },
  "elevation_m": {
    "min": 7.08, "max": 41.21, "mean": 24.77
  },
  "slope_deg": {
    "max": 6.05, "mean": 0.85
  },
  "depressions_count": 572546
}
```

### JSON Attribute Descriptions
- `aoi`: WGS84 geographic bounding box coordinates.
- `grid_resolution_m`: Spatial cell resolution ($30\text{ m}$).
- `dimensions`: Raster cell row and column dimensions.
- `elevation_m.mean`: City average surface elevation in meters ($z$).
- `slope_deg.mean`: City average slope angle in degrees ($\theta^\circ$).
- `depressions_count`: Total count of water-trapping depression sinks in the city catchment.

## 🤖 Feature Attributes Feeding the ML Model (`models/train_surrogate.py`)

The ML surrogate model ingests a 5-element feature vector $X$ extracted dynamically from these processed rasters and Open-Meteo / pySTEPS forecasts:

$$X = \left[ \text{total\_rainfall\_mm}, \text{peak\_intensity\_mm\_hr}, \text{slope\_deg}, \text{elevation\_m}, \text{impermeability\_pct} \right]$$

### Attribute Mapping Table

```text
Processed Input Attributes                      ML Model Input Features (X)            Predicted Output (y)
──────────────────────────                      ───────────────────────────            ────────────────────
pySTEPS Nowcast (precip mm/hr)   ─────────►     X[0] = total_rainfall_mm       ───┐
Open-Meteo Forecast (peak mm/hr) ─────────►     X[1] = peak_intensity_mm_hr    ───┤
[city]_slope.tif (slope_deg)     ─────────►     X[2] = slope_deg               ───┼──► y = predicted_flood_depth_cm
[city]_dem_filled.tif (elev_m)   ─────────►     X[3] = elevation_m             ───┤    (Water level increase cm)
City Profile impermeability %    ─────────►     X[4] = impermeability_pct      ───┘
```

### Risk Level Classification Rules
Based on `predicted_flood_depth_cm` ($y$):

| Water Level Increase ($y$) | Peak Rainfall | Total Rainfall | Assigned Flood Risk Level | UI Marker Color |
|---|---|---|---|---|
| $> 25.0\text{ cm}$ | $> 25.0\text{ mm/hr}$ | $> 50.0\text{ mm}$ | **`SEVERE`** | 🔴 Dark Red (`#991b1b`) |
| $> 12.0\text{ cm}$ | $> 10.0\text{ mm/hr}$ | $> 20.0\text{ mm}$ | **`HIGH`** | 🔴 Red (`#ef4444`) |
| $> 3.0\text{ cm}$ | $> 2.5\text{ mm/hr}$ | $> 5.0\text{ mm}$ | **`MODERATE`** | 🟠 Orange (`#f59e0b`) |
| $> 0.0\text{ cm}$ | $> 0.1\text{ mm/hr}$ | $> 0.1\text{ mm}$ | **`LOW`** | 🔵 Blue (`#3b82f6`) |
| $0.0\text{ cm}$ | $0.0\text{ mm/hr}$ | $0.0\text{ mm}$ | **`NONE`** | 🟢 Green (`#10b981`) |
