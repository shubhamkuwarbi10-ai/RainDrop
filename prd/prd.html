1. Executive Summary & Core Mission

RainDrop GIS is an enterprise-grade urban flood intelligence and emergency response navigation platform built to protect citizens, emergency services, and city planners across India's high-vulnerability metropolitan corridors during extreme monsoon precipitation events.

By combining Doppler radar precipitation nowcasting via pySTEPS (optical flow advection) with 30-meter elevation raster models (ISRO Bhuvan CartoDEM), an ultra-fast Random Forest hydrodynamic ML surrogate model, and an OSRM-powered dual-corridor route navigator, RainDrop predicts street-level water depths and recommends 100% dry elevated bypass corridors before severe inundation occurs.

4. Machine Learning & Physical Model Specifications

4.1 Model 1: pySTEPS Optical Flow Nowcasting Model

Extrapolates radar reflectivity images using semi-Lagrangian advection and Lucas-Kanade dense optical flow fields across 12 lead-time steps (0–180 minutes).

4.2 Model 2: Hydrodynamic Water Depth ML Surrogate Model

Trained on high-fidelity 1D-2D SWMM (Storm Water Management Model) hydraulic simulations to predict street-level flood depths instantly without numerical instability.

Feature Name Description & Physical Unit Importance Weight
total_rainfall_mm Cumulative projected rainfall volume (mm) over forecast horizon 42.8%
peak_intensity_mm_hr Maximum hourly rainfall rate (mm/hr) 28.4%
elevation_m 30m CartoDEM elevation above mean sea level (m MSL) 16.2%
impermeability_pct Urban built-up surface impermeability percentage (%) 8.5%
slope_deg Local terrain slope angle (degrees) derived from D8 gradient 4.1%

6. Execution & Operation Instructions

1. Start the FastAPI Server:

.venv\Scripts\python.exe -m uvicorn server.main:app --host 127.0.0.1 --port 8000

2. Transpile Frontend (after updating client/frontend.jsx):

.venv\Scripts\python.exe pipeline/transpile_frontend.py

3. Retrain Machine Learning Surrogate Model (optional):

.venv\Scripts\python.exe models/train_surrogate.py

4. Access Web Dashboard: Open http://127.0.0.1:8000 in your web browser.
